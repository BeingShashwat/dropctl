Send a file that deletes itself.

dropctl is temporary file sharing without the sign-up. Upload a file, get a short link and a QR code, and choose exactly how long it should live. When the expiry passes the file is deleted from storage, not just hidden.

Limits

Max file size
100 MB
Link lifetime
1 hour → 7 days
Encryption at rest
AES-256
